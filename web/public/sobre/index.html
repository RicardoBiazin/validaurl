ValidaURL

Verificar links quebrados online, grátis

O ValidaURL confere se cada link responde OK (200). Cole uma lista de URLs, rastreie um site inteiro ou leia o sitemap e veja na hora quais endereços dão erro 404, 500, redirect ou não respondem.

Como funciona

Cada URL recebe primeiro um pedido HEAD. Se o HEAD falhar ou responder 400 ou mais, a checagem repete com GET, porque muitos servidores tratam o HEAD errado. A cadeia de redirects é seguida e registrada, com detecção de loop.

Na versão web, as checagens são feitas pelo servidor, porque o navegador não consegue consultar sites de terceiros por causa do CORS. O servidor devolve só o código de status e os links encontrados, nunca o conteúdo das páginas, e bloqueia endereços de redes privadas.

Há também uma versão para Windows, portátil e sem instalação, com os mesmos recursos e linha de comando.

Recursos

  • Lista de URLs: cole o texto ou abra um arquivo TXT, CSV, XLSX ou HTML.
  • Rastrear site: segue os links internos e checa imagens, CSS e JS; mostra em qual página está o link quebrado.
  • Sitemap: aceita sitemap index e .xml.gz; acha o sitemap pelo robots.txt.
  • WHOIS: registrador, datas, DNS (A, AAAA, MX, NS, TXT), reverso dos IPs e mapa.
  • Monitoramento: avisa quando um link passa a falhar ou volta ao normal.
  • Exportação: filtre por resultado ou tipo de arquivo e baixe em CSV.

Perguntas frequentes

O ValidaURL é grátis?

Sim. A versão web e a versão para Windows são gratuitas e o código é aberto, com licença MIT.

Como o ValidaURL decide se um link está quebrado?

Ele manda um HEAD e, se o HEAD falhar ou responder 400 ou mais, repete com GET. Segue a cadeia de redirects, detecta loops e classifica cada URL como OK, redirecionado, erro 4xx, erro 5xx ou falha (DNS, timeout, SSL, conexão recusada).

Dá para verificar um site inteiro?

Sim. O rastreio segue os links internos e checa tudo o que encontrar, inclusive imagens, CSS e JS, e mostra em qual página está cada link quebrado. Também é possível ler o sitemap, inclusive sitemap index e .xml.gz.

O ValidaURL avisa quando um link cair?

Sim. Os monitores repetem a checagem a cada intervalo escolhido, a partir de 5 minutos, e avisam por webhook ou notificação do navegador quando um link passa a falhar ou volta ao normal. Na web eles rodam no servidor, mesmo com o navegador fechado.

Preciso criar conta?

Não. Não há login. Cada monitor recebe um link secreto, e o servidor guarda só o hash da chave.
